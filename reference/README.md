# ksz_2lpt (CPU Reference)

The original CPU implementation by [Dr. Paul La Plante](https://plaplant.github.io/), kept here as a private fork and used as the reference for the GPU port.

The fork is the `ksz_2lpt/` submodule: its own Git repository, pinned by this one at the commit the GPU port is validated against. Source changes are committed and pushed inside `ksz_2lpt/`; this repository then records the new commit, and the notes about it (this README, [CHANGELOG.md](CHANGELOG.md)) are committed out here.
